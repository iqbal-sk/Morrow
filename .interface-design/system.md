# DigUp People

Intent: Iqbal finds personal files by the people in them, enrolls friends, and corrects uncertain face matches without leaving the Mac app. Familiar, calm, and inspectable.

Domain: personal photo library, reference portraits, names and nicknames, group photos, file provenance, unknown faces, search results.
Color world: existing amber magnifier, moss app icon, graphite window backgrounds, native selection blue, neutral photo borders, subdued secondary labels.
Signature: every identity decision carries a face crop and a route to its original file. Reference selection shows every detected face instead of silently choosing the largest.
Defaults replaced: a statistics dashboard becomes a person list and selected person's references; automatic identity guesses become visible match states and corrections; another search screen becomes person context in the existing search panel.

Palette: existing Brand amber for discovery, system accent for selection and primary controls, system semantic colors for errors. No new decorative palette.
Depth: subtle native surface changes and separators, matching Settings. No decorative shadows.
Surfaces: window background, grouped content background, inset text fields. Support light and dark appearances.
Typography: system font, matching Settings; headline for person name, secondary captions for references and file provenance. Scores are diagnostic, not presented as probability.
Spacing: 4-point base; 8 between related controls, 12 within groups, 20–24 between sections.
States: empty enrollment, photo detection, multiple-face selection, indexing progress/cancel, empty review, error/retry, ambiguous names, references unavailable after model changes.
Accessibility: named buttons, keyboard selection, visible text status alongside color, native focus and adequate click targets.

People lives in Settings alongside Folders. Search stays in the existing panel/window. Curated identities and references survive content-index rebuilds.
